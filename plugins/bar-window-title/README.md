# Window title

The focused window's title in the bar, next to the workspaces. Nothing
when no window has the focus, so the bar never keeps showing a window
that's gone. When the bar is short of room, the title gives way first.

`max_width` is the longest it may get (520 logical pixels); longer titles
end in "…". `font_size` is the size of the text (9.5 points).
