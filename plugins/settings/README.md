# Settings

The settings everyone needs, a page each (`SUPER + comma`): the
keyboard (the one in use, any other by search, a field to try it), the
touchpad and the mouse (tap to click, natural scrolling, off while
typing, speed), the default apps (each kind's installed ones), the
language and the time zone, and the screens, theme and wallpaper (their
own panels). Each change is a `myarch apply`: on the timeline, undoable.
Every plugin's other settings are in the Plugins panel.
