# Ajustes

Los ajustes que todos necesitan, una página cada uno (`SUPER + coma`):
el teclado (el que usas, cualquier otro con búsqueda, un campo para
probarlo), el touchpad y el ratón (tocar para hacer clic, desplazamiento
natural, apagado al escribir, velocidad), las apps por defecto (las
instaladas de cada tipo), el idioma y la zona horaria, y las pantallas,
el tema y el fondo (en sus propios paneles). Cada cambio es un
`myarch apply`: queda en el historial y se puede deshacer. Los demás
ajustes de cada plugin están en el panel de Plugins.
