# Tema de Firefox

Firefox y sus derivados (Zen, LibreWolf, Floorp, Waterfox) con el tema, en
cada perfil: el marco del navegador (pestañas, barra de herramientas,
barra de direcciones, menús, barra lateral, también sus esquinas) y sus
propias páginas (nueva pestaña, ajustes, complementos). Los sitios web
conservan sus colores. Thunderbird y Mullvad Browser quedan fuera.

Firefox lo lee al arrancar: reinícialo para ver un tema nuevo.

Es una hoja de estilos en la carpeta `chrome` de cada perfil, importada
desde userChrome.css y userContent.css, más el único ajuste en user.js que
deja a Firefox leerlas. Esos archivos pueden ser tuyos (mods de Zen, tu
propio CSS, arkenfox): solo las líneas de Mazapán son suyas, el resto queda
como lo escribiste. En modo de alto contraste los colores del navegador no
se tocan.
