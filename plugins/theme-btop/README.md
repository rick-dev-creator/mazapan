# btop theme

btop, the system monitor in the terminal, in the theme's colors: its boxes
and lines, the selected row in the accent, and graphs and meters in the
theme's status colors, running from calm to hot. The background is the
terminal's, so a see-through terminal stays see-through.

It's a btop theme of its own (`~/.config/btop/themes/mazapan.theme`),
chosen in btop.conf. btop keeps its own settings in that file too: only the
two about the theme are Mazapan's, the rest stay as you left them.

btop takes a new theme the next time it starts.
