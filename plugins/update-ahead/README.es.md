# Actualizaciones descargadas de antemano

Las actualizaciones que haya, descargadas en segundo plano a la caché de
pacman mientras la computadora está enchufada y con una conexión que no se
cobra por uso: cuando actualizas, tarda un momento. No se instala nada
hasta que lo digas (`mazapan update`, o el panel de actualizaciones).

Descarga con `checkupdates -d`, desde una base de datos propia: la del
sistema no se sincroniza a tus espaldas.
