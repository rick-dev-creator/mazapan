# foot theme

foot, the terminal, in the theme: its font and size, its 16 colors, the
background with the theme's opacity (see-through in some themes), the
selection, links, and a blinking block cursor in the accent color. The 16
colors reach every app that runs in the terminal too.

It's foot's config file, `~/.config/foot/foot.ini`. foot doesn't reload
it by itself: new windows read it, and the terminals already open are
recolored at once, so a new theme shows everywhere. The theme picker does
the same to preview a theme in your open terminals.
