# Hyprland theme

The windows in the theme: the border around them and its width (the
accent on the one in focus, the theme's border color on the rest), the
rounding of their corners, the gaps between them and around the screen,
the color behind them, and blur behind see-through windows when the theme
has it. No shadows.

And how things move, from the theme's timing: windows open with a little
bounce, close quickly, glide when moved, and workspaces slide. A theme
with motion off has no animations.

It's a file Hyprland loads (`~/.config/hypr/mazapan/theme.lua`), reloaded
when a theme is applied, so it shows at once. Through it the theme picker
previews borders, corners and blur on your real windows.
