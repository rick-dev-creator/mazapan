# Power

Lock, suspend, log out, reboot and shut down. The ⏻ button in the middle
of the bar, next to the clock, opens a card with who's logged in and how
long the computer has been up, then the five, each with the command it
runs. Log out, reboot and shut down ask for a second click (or ↵), so a
stray one can't end your session; ↑↓ and ↵ work too. All five are in the
palette as well, where the same three ask first.

`SUPER + L` locks. Suspending locks first.

The lock screen (hyprlock, `~/.config/hypr/hyprlock.conf`) is in the
theme, like a terminal waiting for you: the time (12 or 24 hours, like
the bar's clock in your language), the date, a line with your user and
the computer's name, and the password field.

Settings: `lock_key` (`SUPER + L`); `bar` (on) shows the button in the
bar.
