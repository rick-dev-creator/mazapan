# Boot menu in the theme

GRUB's menu in the theme's colors (the snapshots' entries too): one design
from the first screen to the desktop. A new theme reaches it on the next
`mazapan apply --system`.

GRUB's theme is written next to grub.cfg by a script grub-mkconfig runs
(`/etc/grub.d/mazapan_theme`); taking the plugin off removes both.
