# Tema de VS Code

VS Code, Code - OSS y VSCodium (también sus Flatpaks) con el tema: la
ventana, el editor, los colores de sintaxis y semánticos, y los 16 colores
del terminal. VS Code queda siguiendo el oscuro o claro del sistema, que
pone el tema.

Los colores van en tu settings.json como personalizaciones del tema por
defecto de VS Code (como se llame en tu versión: "Dark 2026", "Dark
Modern"…). Si eliges otro tema en VS Code, simplemente no se aplican a él.
Solo esas claves son de Mazapán; el resto del archivo sigue siendo tuyo,
con su formato. Un settings.json con comentarios no se toca.

Las ventanas abiertas siguen un tema nuevo al momento; pasar de oscuro a
claro, o al revés, requiere reiniciar VS Code.
