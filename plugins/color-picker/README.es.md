# Selector de color

`SUPER + SHIFT + C` (o "Tomar un color" en la paleta) congela las
pantallas para que hagas clic en cualquier color. Se copia como lo
escribe CSS (`format`: `#332925`, `rgb(51, 41, 37)` o
`hsl(17, 16%, 17%)`), y una notificación dice cuál, con una muestra.
Esc no toma ninguno. Con hyprpicker.
