# Input method

Typing Chinese, Japanese and Korean in every app: fcitx5 with Pinyin,
Mozc and Hangul, started with Hyprland. Its first start picks the method
for the system's language; `CTRL + SPACE` switches between it and the
keyboard's layout, and fcitx5-configtool changes the rest.

Off until asked: the installer turns it on where the language is
Chinese, Japanese or Korean.
