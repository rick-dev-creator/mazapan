# Método de entrada

Escribir en chino, japonés y coreano en todas las apps: fcitx5 con
Pinyin, Mozc y Hangul, iniciado con Hyprland. Su primer inicio elige el
método del idioma del sistema; `CTRL + ESPACIO` cambia entre él y la
distribución del teclado, y fcitx5-configtool cambia lo demás.

Apagado hasta que se pida: el instalador lo activa donde el idioma es
chino, japonés o coreano.
