# Emulation

Turned on with the Retro and emulators apps (RetroArch, DuckStation,
PCSX2, Dolphin, PPSSPP, melonDS, Azahar, Cemu, RPCS3, xemu…):

- `~/Games/ROMs`, a folder per console, for your games, and `~/Games/BIOS`
  for the consoles' BIOS, with a list of which file each emulator looks
  for (`games` moves them elsewhere). "Open my games folder" in the palette.
- RetroArch set up the first time it's there: its menu (Ozone), your
  games' folder, the BIOS folder, fullscreen, controllers recognized,
  saved where you left off. It keeps its own settings after that.
- Emulators' windows never let the screen dim or lock while in front, and
  draw the moment they're ready (less delay).

Games and BIOS are yours: copies of cartridges, discs and consoles you
own. Mazapan installs the emulators, never games or BIOS. Nintendo
Switch emulators aren't offered: Nintendo has had them taken down.
